第1部 特殊相対性理論 ／ 02

なぜ、速く動くと
時間が遅れるのか

「速いから時間が遅くなる」と言われても、納得できなかった。速さと時間は別のものではないのか。だが前の章の前提を一つ認めてしまうと、この結論は避けられなくなる。中学校で習う三角形の定理だけで、そこまで辿り着ける。

この章の要点
  • 光で時を刻む時計を考えると、動いている時計では光の経路が斜めに伸びる。
  • 経路が伸びても光速は変わらないので、外から見ると1回の往復に余計に時間がかかる。
  • 遅れの大きさはローレンツ因子 γ で決まる。光速の90%でおよそ2.3倍。
  • 動いている本人は、自分の時間が遅れたとはまったく感じない。
  • 飛行機や宇宙ステーションの時計でも、実際にナノ秒・マイクロ秒の単位で確かめられている。

光で時を刻む時計

納得するために、いちばん単純な時計を考える。向かい合わせに置いた二枚の鏡のあいだを、光が往復する。一往復を「1カチッ」と数える。それだけの時計だ。中身が光だけなので、光速不変の原理がそのまま効いてくる。

この時計を、まず机の上に静かに置く。光はまっすぐ上下に往復し、規則正しく時を刻む。

次に、この時計をロケットに積んで、横方向に高速で飛ばす。ロケットの中にいる人から見れば、何も変わらない。光は相変わらず上下に往復している。ところが外で見送っている人から見ると、光が下の鏡を出て上の鏡に着くまでのあいだに、時計そのものが横にずれている。だから光は、斜めの経路を進んだように見える。

ここで前提が効く。光の速さは、どちらの立場でも同じ c だ。速さが同じで距離が長いなら、かかる時間は長い。つまり外から見ると、動いている時計の「1カチッ」には、余計に時間がかかっている。時計が遅れて見える。

光時計は特別な装置ではないか、という疑問は当然出てくる。だがもし光時計だけが遅れて腕時計が遅れないなら、ロケットの中で二つを見比べるだけで「自分は動いている」と分かってしまい、相対性原理が壊れる。遅れるのは時計ではなく、その立場における時間そのものでなければならない。

三角形ひとつで、式が出る

斜めの経路は、直角三角形の斜辺になっている。縦の辺は鏡の間隔、横の辺は時計が動いた距離、斜辺は光が実際に進んだ距離だ。

三平方の定理をそのまま当てはめる。

( c t )2 ＝ ( c t′ )2 ＋ ( v t )2 整理すると t ＝ t′ ／ √( 1 − v2／c2 ) ＝ γ t′

この γ（ガンマ）をローレンツ因子と呼ぶ。中の人の1秒が、外から見ると γ 秒に引き伸ばされる。難しい物理は一つも使っていない。「光速はどちらから見ても同じ」を一度認めただけで、こうなってしまう。

速さγ中の人の1年は、外では
時速900km（旅客機）1.00000000000031年＋約10マイクロ秒
秒速7.7km（宇宙ステーション）1.00000000031年＋約10ミリ秒
光速の10%1.005約1年と1.8日
光速の50%1.155約1年と57日
光速の90%2.294約2年3か月
光速の99%7.089約7年
光速の99.9%22.37約22年

日常の速さでは、γ は 1 と区別がつかないほど 1 に近い。飛行機によく乗る人と、ほとんど乗らない人のあいだにも原理的には差が生じているが、その差は一生かけてもナノ秒の単位にしかならない。相対論が「特殊な宇宙の話」に見えるのは、私たちが遅すぎるからだ。

逆に、v が c に近づくと γ は急激に大きくなり、v ＝ c では分母がゼロになって発散する。質量を持つものが光速に到達できないのは、この式がそこで破綻するからでもある。

「遅れる」は、本人にとっての遅さではない

ここは誤解しやすいところで、自分も最初に引っかかった。

よくある誤解

✕　高速で移動する人は、自分の時間がゆっくり進むのを感じる。世界がスローモーションに見える。

○　本人にとっては何も変わらない。時計は正常に進み、心臓も普通に打ち、コーヒーも普通に冷める。自分の時間が遅れていると感じる瞬間は、一度もない。

相対性理論が言っているのは、異なる経路をたどった二人が再会して時計を見比べたとき、経過した時間が違っているということだ。「今この瞬間に誰の時間が遅いか」という問いではない。比べられるのは、出発から再会までに刻まれた総量だけになる。

それぞれが自分の時間を、ごく普通に生きている。違うのは、再会したときに手元に溜まっている時間の量のほう。

さらにややこしいのは、遅れ方がお互いさまだという点だ。地球から見ると宇宙船の時計が遅れている。だが宇宙船から見れば、遠ざかっているのは地球のほうで、地球の時計が遅れている。等速で動いているかぎり、どちらが「本当に動いている」とは言えないのだから、そうなるしかない。

ではなぜ、宇宙船で旅に出た双子だけが若いまま帰ってくるのか。矛盾しているように見えるこの問題は、実は「どちらが動いたか」では解けない。二人がたどった時空の中での経路を比べると、きれいに解ける。それが次の章になる。

本当に起きている、という証拠

空から降ってくるミュー粒子

宇宙線が大気の上層にぶつかると、ミュー粒子という粒子が生まれる。高度はおよそ15km。ミュー粒子は不安定で、平均2.2マイクロ秒ほどで崩壊してしまう。光速で進んだとしても、その間に進める距離はわずか660mほどしかない。計算上、地上に届くはずがない。

ところが実際には、大量のミュー粒子が地上で観測される。ミュー粒子は光速に近い速さで飛んでいるので、地上から見ればその内部時計が大きく引き伸ばされ、崩壊するまでに15kmを走りきってしまう。1963年の山岳での観測以来、この「届くはずのないものが届く」現象は繰り返し確かめられている。

面白いのは、ミュー粒子自身の立場から見ても矛盾しない点だ。ミュー粒子にとって自分の寿命は2.2マイクロ秒のままだが、そのかわり進行方向の距離が縮んで、大気の厚さが15kmではなく数百mになっている。時間の遅れと長さの縮みは、同じ一つの現象を別の側から見たもので、どちらの立場から計算しても「地上に届く」という同じ結論になる。

飛行機に乗ると、時計はどうずれるか

1971年、ヘイフリーとキーティングが原子時計を旅客機に積んで地球を一周させ、地上に置いた時計と比べた。結果は、東回りで約59ナノ秒の遅れ、西回りで約273ナノ秒の進み。理論の予測とよく一致した。

東と西で符号が変わるのは、地球そのものが自転しているためだ。速度による遅れは、地球の中心から見た速さで決まる。東回りの飛行機は自転に速さを足す形になり、西回りは差し引く形になる。

さらに、飛行機では高度による効果も同時に効いてくる。これは次の章の先取りになるが、高いところでは時間が速く進む。10時間のフライトで見積もると、おおよそこうなる。

速度による効果 約13ナノ秒 遅れる

時速900kmで10時間。地上に残った人より、わずかに時計が遅れる。

高度による効果 約39ナノ秒 進む

高度10kmでは重力がわずかに弱く、時間が速く進む。こちらのほうが大きい。

差し引きすると、フライト1回あたり20〜30ナノ秒ほど先に進む。「飛行機によく乗る人は時間が遅れているのでは」と考えていたが、実際には逆で、ごくわずかに未来側へずれていることになる。もっとも、一生飛び続けても、その総量はまばたき一回にも遠く及ばない。

そして今日、この効果は無視できない場面がある。GPS衛星の時計は、補正しなければ1日で数十マイクロ秒ずれてしまい、位置が数kmも狂う。カーナビが正しく動いているという事実そのものが、相対論が日常世界で成立している証拠になっている。

残る問い

  • お互いに相手の時計が遅れて見えるのに、再会したときの差は一意に決まる。その非対称はどこから来るのか。
  • 時間の遅れと長さの縮みが同じ現象の裏表だとすれば、時間と空間はどこまで同じものなのか。
