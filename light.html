第1部 特殊相対性理論 ／ 01

光の速さは、
誰から見ても同じ

時間の話を始めるのに、まず光の話から入る。遠回りに見えるが、逆だった。時間が遅れる理由をどこまでも掘っていくと、最後に残るのはこの一点だけになる。ここが動かせない土台で、時間のほうが土台に合わせて動く。

この章の要点
  • 速度はふつう足し算になる。電車の上で投げたボールは、地上から見れば電車の分だけ速い。
  • ところが光だけは足し算にならない。誰が、どんな速さで動きながら測っても、光の速さは同じ値になる。
  • 「何に対して止まっているか」の絶対的な基準は、探しても見つからなかった。
  • この二つを認めると、時間と空間のほうが観測者ごとに変わらざるをえなくなる。

速度は、足し算になるはずだった

時速100kmで走る電車の中で、進行方向に時速20kmでボールを投げる。地上に立っている人から見れば、ボールは時速120kmで飛んでいく。誰でも納得できるし、実際その通りになる。速さというのは、こうやって足したり引いたりできる量だ——ガリレオの時代から、それが当たり前だった。

ならば光でも同じはずだ。光速の90%で飛ぶ宇宙船から、前方に光を出す。外から見れば、光は光速の1.9倍で進んでいるように見えるだろう。そう予想して測ってみると、そうならない。光はやはり、ちょうど光速で進んでいる。

19世紀の終わり、光は「エーテル」という見えない媒質の波だと考えられていた。音が空気を伝わるように、光も何かを伝わっているはずだ、と。もしそうなら、地球はエーテルの中を公転しているのだから、進行方向とその横向きとでは光の速さが違って測れるはずだった。

1887年、マイケルソンとモーリーがこの差を測る実験を行った。装置の精度は十分にあったのに、差は出なかった。地球がどちらを向いていても、光の速さは同じだった。その後、光共振器を使った現代の実験でも、けた違いの精度で同じ結論が繰り返されている。

そこで、前提のほうを取り替えた

1905年、アインシュタインは説明を諦めるかわりに、観測されたことをそのまま出発点に据えた。特殊相対性理論が置いた前提は、たった二つしかない。

  1. 相対性原理

    等速で動いているすべての立場（慣性系）で、物理法則は同じ形をしている。窓のない部屋の中でどんな実験をしても、自分が「止まっている」のか「等速で動いている」のかは決められない。

  2. 光速不変の原理

    真空中の光の速さ c は、光源が動いていても、観測者が動いていても、同じ値になる。

この二つはどちらも穏当に見えるが、並べると強烈な結論が出てくる。速さとは「距離 ÷ 時間」だ。距離も時間も観測者によらず決まっていて、なおかつ光速だけが誰にとっても同じ、ということはありえない。どちらかを諦めなければならない。

アインシュタインが諦めたのは、距離と時間のほうが誰にとっても同じという前提だった。

時間が変化するから光速が一定になるのではない。光速が一定であるという宇宙の性質から、時間と空間のあり方が決まってくる。

向きが逆であることが、ここでは大事になる。光速不変は結果ではなく前提で、時間の遅れのほうが、そこから導かれる結果のほうだ。

足し算の、本当の形

では日常の足し算は間違いだったのか、というとそうではない。正しい合成則は、こういう形をしている。

w ＝ ( u ＋ v ) ／ ( 1 ＋ uv ／ c2 ) u：電車から見たボールの速さ ／ v：地上から見た電車の速さ ／ w：地上から見たボールの速さ

日常の速さでは uv/c² が途方もなく小さいので、分母はほぼ 1 になり、w ≒ u + v に戻る。時速120kmは正しい。ずれは小数点以下、何十桁も先にある。

ところが u に c を入れると、分子は c + v、分母は 1 + v/c となり、計算すると答えはぴったり c になる。どんな v を入れても c のままだ。足し算の式そのものに、「光速を超えられない」という性質が最初から織り込まれている。

何に対しての、速さなのか

ここでもう一つの疑問が出てくる。地球は自転し、太陽のまわりを回り、太陽系は銀河を回り、銀河も動いている。宇宙そのものが膨張している。そもそも私たちは、何に対して速さを測っているのか。

答えは、拍子抜けするほど単純だった。基準はない。「絶対に止まっている場所」は、どれだけ探しても見つからなかった。だから「速さ」という言葉は、必ず「何に対して」を伴わないと意味をなさない。

ただし例外がひとつある。光速 c だけは、どの立場から測っても同じ値になる。相対的でない量が、この宇宙にひとつだけある。だからこそ c は、単なる「光の速さ」を超えた意味を持つ。時間と空間を結びつける、宇宙の変換定数のようなものだ。

実際いまでは、c は測る量ですらない。1983年に、1メートルのほうが「光が1秒の299,792,458分の1のあいだに進む距離」として定義し直された。c＝299,792,458 m/s は、測定値ではなく定義値になっている。

ことばの整理
慣性系
加速していない立場のこと。等速で動いているか、止まっているか。その区別自体ができないので、両者は同じものとして扱われる。
光速不変の原理
真空中の光速 c が、光源の運動にも観測者の運動にもよらないこと。特殊相対性理論の第二の前提。

秒速およそ30万km。ただし本質は「光の速さ」ではなく、質量ゼロのものが必ず出す速さであり、時間と空間を結ぶ換算係数でもある。

では、なぜ光速は一定なのか

ここが行き止まりになる。相対性理論の内側では、この問いに答えは出ない。光速不変は理論が説明する対象ではなく、理論が立つための土台として置かれているからだ。

手がかりがないわけではない。マクスウェルが電磁気の法則をまとめたとき、光の速さは真空そのものの性質だけから決まる形で式に現れた。そこには「誰から見て」という余地が入っていない。理論の形のほうが、最初から観測者を選ばない作りになっていた。

ただし、それは「なぜ電磁気の法則がその形なのか」に問いを移しただけとも言える。さらに掘れば「なぜ宇宙はこの基本法則を持っているのか」という、物理学そのものの外側に近い問いになる。このノートでは、そこは開いたまま先へ進む。

よくある誤解

✕　光はとても速いので、日常では足し算の誤差が見えないだけ。

○　速さの問題ではない。光速は「速度の上限」であり、時空の構造そのものに組み込まれた定数。質量ゼロの粒子は必ず c で進み、それより遅くも速くもなれない。逆に質量を持つものは、どれだけエネルギーを注いでも c に到達できない。

残る問い

  • なぜ宇宙の基本法則は、観測者を選ばない形をしているのか。
  • c は「光の速さ」なのか、それとも先に時空の構造として c があり、光がたまたまそれに乗っているだけなのか。
