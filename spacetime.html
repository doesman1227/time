第2部 時空 ／ 03

XYZ に T を
足しただけではない

「時空」という言葉を聞いたとき、空間のXYZに時間のT軸を1本足した4次元の座標だろう、と考えた。入口としては間違っていない。だが、それだけでは時空の肝心なところが落ちてしまう。落ちているのは、4本目の軸が他の3本と同じようには足されないという一点だ。

この章の要点
  • 時空では、時間の項だけ符号が逆になる。ここが「ただの4次元」との決定的な違い。
  • 長さも時間の長さも観測者ごとに変わるが、両者を組み合わせた時空間隔だけは全員で一致する。
  • 物体は時空の中に一本の線（世界線）を描く。止まっていても、時間方向には進んでいる。
  • その線に沿って自分の時計が刻んだ量が固有時。時間の遅れとは、線ごとに固有時が違うということ。
  • 時空では、二点をまっすぐ結んだ人がいちばん多く歳をとる。

4本目の軸は、少し違う足され方をする

ふつうの3次元空間では、二点の距離はこう決まる。

d2 ＝ x2 ＋ y2 ＋ z2

ここに時間を4本目の軸として素直に足すなら、全部プラスで並ぶはずだ。ところが時空で「全員が一致する量」を探すと、出てくる形はこうなる。

s2 ＝ ( c t )2 − ( x2 ＋ y2 ＋ z2 ) 時間の項と空間の項が、引き算で結ばれている

マイナスが一つ入っているだけだが、これが時空を時空たらしめている。時間は空間の4本目ではなく、符号の違う方向として空間に組み込まれている。c が掛かっているのも大事で、秒とメートルという別々の単位を同じ土俵に乗せる換算係数の役をしている。時間に光速を掛けると、距離になる。

そして、この s² という量には特別な性質がある。ある人が測った時間 t も距離 x も、別の速さで動く人が測ればどちらも違う値になる。それなのに、この組み合わせだけは全員がぴったり同じ値を出す。

時間も距離も、観測者ごとに伸び縮みする。伸び縮みしない実体は、その二つを組み合わせたところにある。だから時間と空間を別々に扱うのをやめて、ひとつの「時空」と呼ぶ。

比喩を使うなら、地図の上で棒を回転させるようなものだ。棒を回せば、東西方向の成分も南北方向の成分も変わる。しかし棒の長さは変わらない。時空でも同じことが起きていて、速さを変えるというのは、時間方向と空間方向への成分の配分を変える操作にあたる。配分は変わるが、s² は変わらない。ただし符号が違うぶん、この「回転」は円ではなく双曲線を描く——それが、いくら配分を変えても光速を超えられない理由になっている。

世界線 — 止まっていても、進んでいる

時空の中では、物体は「点」ではなく「線」として存在する。生まれてから消えるまでの全履歴が、一本のつながった線になる。これを世界線と呼ぶ。

縦軸に時間、横軸に空間をとった図が、いちばん見やすい。じっと座っている人の世界線は、まっすぐ上へ伸びる垂直な線だ。空間的には動いていないが、時間方向には進み続けている。等速で歩いている人の世界線は、斜めに傾いた直線になる。速いほど、線は寝る。

光の世界線は、ちょうど45度になる（縦軸を ct にとった場合）。質量を持つものの世界線は、必ずこれより立っている。この45度の線が作る領域を光円錐と呼び、「いま・ここ」から影響を及ぼせる範囲、影響を受けられる範囲を区切っている。時空には、行ける場所と行けない場所が構造として書き込まれている。

ことばの整理
世界線
ある物体が時空に描く一本の線。その物体の全履歴そのもの。
固有時
世界線に沿って、その物体自身の時計が刻んだ時間。誰から見ても同じ値になる。記号は τ（タウ）。
光円錐
ある事象から光が届く範囲。因果関係を持てる相手と、持てない相手を分ける境界。

固有時 — 線の長さとしての時間

世界線に沿って、その人自身の時計が刻んだ時間を固有時という。時空の図でいえば、線の「長さ」にあたる量だ。前の章の式を書き直すと、こうなる。

( c τ )2 ＝ ( c t )2 − x2 τ：本人の時計が刻んだ時間（固有時） ／ t, x：外から見た時間と移動距離

ここに x ＝ vt を入れて整理すると、τ ＝ t√(1−v²/c²) ＝ t/γ になる。第1部で光時計から出した式と、まったく同じものだ。光時計の話は、この一般的な式を一つの具体例で見ていたにすぎなかった。

言い換えると、時間の遅れとは、世界線ごとに固有時の溜まり方が違うということでしかない。時間が何かにせき止められているのでも、時計の精度が落ちているのでもない。

ここで、日常の直感と正反対のことが起きる。ふつうの空間では、二点を結ぶ最短経路は直線で、寄り道をすれば道のりは長くなる。ところが時空では、時間の項の符号が逆になっているせいで、関係がひっくり返る。

時空では、二つの出来事をまっすぐ結んだ世界線が、いちばん長い固有時を持つ。寄り道をした人ほど、歳をとらない。

双子のパラドックスが、これで解ける

前の章で残していた問題に戻る。地球に残った双子と、宇宙船で旅に出た双子。等速で動いているあいだは「お互いに相手が遅れて見える」のに、再会したときにはなぜ旅に出たほうだけが若いのか。

時空の図に描けば、非対称は一目でわかる。二人は同じ点から出発し、同じ点で再会する。地球に残ったほうの世界線は、その二点をまっすぐ結んでいる。旅に出たほうは、途中で折れ曲がっている。

対称性を破っているのは「どちらが動いたか」ではなく、折り返したのはどちらかだ。旅に出た双子は途中で向きを変えている。そのあいだ、彼は加速していて、慣性系を乗り換えている。地球に残ったほうは最初から最後までひとつの慣性系にいた。「お互いさま」が成り立つのは等速のあいだだけで、折り返しがその対称性を破る。

だから双子問題は、突き詰めると幾何の問題になる。同じ二点を結ぶ経路のうち、まっすぐな経路が固有時最大。曲がった経路は必ず短い。どちらの時計が正しいかという話ではなく、二人が通った道のりの長さが違った、それだけのことだった。

「いつ」と「どこ」は、切り離せない

もう一つ、時空がひとつの構造であることを強く示す事実がある。同時の相対性だ。

長い列車の中央から、前と後ろへ同時に光を出す。車内の人にとって、光は前後の壁に同時に届く。ところが線路脇で見ている人にとっては、後ろの壁は光に近づいてきて、前の壁は逃げていく。光速はどちらの向きでも同じなのだから、この人にとっては後ろの壁に先に届く。

つまり、ある人にとって同時に起きた二つの出来事が、別の人にとっては同時ではない。「いま、宇宙の向こうで何が起きているか」という問いには、立場によって違う答えが出る。誰の答えが正しいというのでもなく、どちらも正しい。

これが、時空という考え方にたどり着く最後の押しになった。「どこにいるか」と「いつそこにいるか」を独立に決めることができない以上、空間と時間を別々の入れ物として扱うのは、もう無理がある。

補助の比喩と、その限界

「すべてのものは時空の中を光速で進んでいて、空間方向に速く動くぶんだけ、時間方向の進みが減る」——時間の遅れを直感的に掴むのに、この言い方はよく使われる。実際、感覚をつかむ入口としてはとても効く。

ただしこれは厳密な表現ではない。「時空を進む速さ」という量は、時間で時間を割ることになっていて、標準的な定義があるわけではない。イメージの足場として使い、詰める段では s² と固有時の式に戻るのがいい。

残る問い

  • 時空の全体が最初から一枚の構造として存在しているなら、「いま」という特別な瞬間はどこにあるのか。
  • 時間の項の符号だけがなぜ逆なのか。それは宇宙のどんな性質から来ているのか。
  • 世界線が時空に描かれているのだとしたら、未来もすでに描き終わっているのか。
